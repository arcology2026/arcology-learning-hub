AI 輸出格式

同一個問題，不一定只能叫 AI「回答」。先決定你希望資訊怎麼被理解，再指定適合的輸出形式。

01 / TEXT

簡潔文字｜航太文件 ASD-STE100 清晰寫作

適合：技術說明、SOP、報告摘要、教育訓練、新手說明。
請用中文解釋【主題】。 寫作時借用 ASD-STE100 的清晰寫作原則： 1. 句子要短，每句盡量不超過 30 個字。 2. 一句只講一件事。 3. 同一個概念從頭到尾使用同一個詞。 4. 使用主動語態，讓每句的主詞清楚。 5. 避免堆疊名詞與不必要的術語。 6. 術語第一次出現時，用白話簡短說明。 這是中文清晰寫作要求，不代表符合正式 ASD-STE100 英文規範。
02 / VISUAL

一張圖｜把複雜概念視覺化

適合：流程、系統架構、因果關係、工作流程、技術原理。
請用一張圖解釋【主題】，不要使用長篇文字。 圖中請包含： 1. 關鍵元件 2. 元件之間的關係 3. 流程或資訊移動方向 4. 必要的箭頭或連接線 5. 每個標籤不超過 10 個字 讓第一次接觸這個主題的人，也能從圖中理解整體關係。
AI 可能直接產生圖片，也可能輸出 Mermaid 等圖表程式碼。
03 / INTERACTIVE

互動網頁｜HTML 單頁互動解說

適合：教學模擬器、計算工具、互動教材、參數比較、Vibe Coding 入門。
請用 HTML 製作一個單頁互動網頁，解釋【主題】。 網頁需要包含： 1. 簡潔的主題說明 2. 可以點開或收合的段落說明 3. 至少一個可以操作的互動元件 4. 使用者調整參數後，可以立即看到結果變化 5. 適合手機與電腦瀏覽 6. 所有 HTML、CSS、JavaScript 都放在同一個檔案 請輸出可以直接儲存為 .html 並用瀏覽器開啟的完整程式碼。
