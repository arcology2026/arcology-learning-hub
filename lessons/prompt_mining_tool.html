Tool Box · Prompt Mining

Prompt 挖掘工具

先把想法整理成結構，再針對差異修正；成果滿意後，將成功方法萃取成可重複使用的 Prompt 模板。

結構化提問 → Delta 修正 → 模板萃取 → Prompt Library
01 / STRUCTURE

把想法說清楚｜Markdown 六元素模板

適合：第一次提問時，整理目標、背景、資源、限制、交付與驗收。
# [主題] ## 目標 {我想完成什麼？} ## 背景 {這項任務發生在什麼情境？誰會使用？為什麼需要？} ## 資源 {我目前有哪些資料、附件、工具、範例或參考內容？} ## 限制 {有哪些不能改、不能做、必須遵守的條件？} ## 交付 {最後要產出什麼？文字、圖卡、簡報、HTML、表格或其他格式？} ## 驗收 {怎樣才算完成？我要用哪些條件判斷成果是否符合需求？}
02 / DELTA

不用重來，只改差異｜Delta Prompt 調味料

適合：第一版已經產出，只補充「保留、修改、新增、不要修改、驗收」。
# [主題]｜Delta Prompt ## 基準 {以上一版成果、附件或指定版本作為修改基準。} ## 保留 以下內容請維持不變： - {需要保留的內容} - {需要保留的格式} - {需要保留的風格} ## 修改 請修改以下內容： - {需要修改的內容} - {目前哪裡不符合需求} - {希望改成什麼} ## 新增 請增加以下內容： - {需要補充的新資訊} - {需要增加的功能} - {需要增加的說明} ## 不要修改 以下內容不得變更： - {不能改動的內容} - {不能刪除的功能} - {不能改變的條件} ## 驗收 修改完成後，請自行檢查： 1. {驗收條件} 2. {驗收條件} 3. {驗收條件}
調味料概念：主體已經完成，不重新做，只說清楚哪裡加、哪裡減、哪裡保持不變。
03 / EXTRACT

把成功留下來｜模板萃取

適合：成果已驗收滿意，把一次性的案例去除，萃取成可重複使用的 Markdown Prompt Template。
# [主題]｜模板萃取 請比較以下內容： 1. {原始 Prompt} 2. {Delta Prompt} 3. {最終滿意成果} 請分析這次成功的提問方式。 不要保留本次案例中的特定： - 人名 - 公司名 - 產品名 - 數字 - 專案名稱 - 個別情境 請保留可以重複使用的： - 任務結構 - 提問邏輯 - 限制條件 - 輸出要求 - 驗收方法 請將需要在下次使用時替換的內容， 改寫成： {元素} 最後請整理成一份可以直接重複使用的 Markdown Prompt Template。 輸出格式如下： # [主題] ## 目標 {元素} ## 背景 {元素} ## 資源 {元素} ## 限制 {元素} ## 交付 {元素} ## 驗收 {元素}
